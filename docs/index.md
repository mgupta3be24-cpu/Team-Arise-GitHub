# Project Page

The master template comes with a CI/CD Pipeline to publish your documentation as under folder `docs`.

However, in order to publish it the first time, you need to activate GitHub Pages with the following settings:

## Project Page

The resultant is your Project Page!

## Journal Entries

Each team member is required to write a journal, with an update frequency of at least once weekly.

Journal is in Markdown format under folder `journals`.

Each member should create their journal space as a folder with name:

`ROLLNO-FIRSTNAME`

For example:

`1024030xxx-bhanurekha`

The output is expected to be an exercise in technical writing, instead of creative writing.

### Journal Topics

1. Using MWE as a start point
2. Using Journal Structure

From an evaluation point of view, a journal is a proof of your due diligence and progress.

From a learning point of view, a journal is a quick ready reckoner / collection of your solutions, patterns, snippets, boilerplates, long before they are mature enough to be published.

## Progress Reports

1. **Project Proposal**

2. **Prototype Stage Progress Report**

   `project-report-prototype-stage`

3. **Final Project Report**

   `project-report-final`
